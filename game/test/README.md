## 여기서 실제로 잡은 버그들

| 증상 | 원인 |
|---|---|
| **세이브 71번이면 에뮬레이터가 죽음** | `_file_data_delete` 뒤에 `_free(ptr)` 안 함. 한 번에 195KB 영구 소실 |
| **세 번째 게임 시작에서 터짐** | 롬을 직접 `_free` — `_emulator_delete` 가 이미 반납. 두 번 반납 |
| 같은 롬을 다시 넣으면 저장이 사라짐 | `tx()` 가 결과를 벗기는 방식이 제각각이라 "이미 있나" 검사가 항상 거짓 |
| 불러오기 실패를 성공이라고 말함 | `_emulator_read_state` 반환값을 버림 |
| 롬 읽는 사이에 나가면 뒤에서 계속 돎 | 시작할 때 세대(epoch) 대조를 안 함 |
| 다른 앱 갔다 오면 멈춘 채로 갇힘 | `visible` 로 돌아왔을 때 처리가 없음 |
| 낡은 기록 하나가 목록 전체를 날림 | `r.states.map` 이 터지면 목록이 통째로 실패 |
| **전체화면이 영영 안 풀림** | `exitFull()` 이 아예 없는데 `try{}catch{}` 가 삼킴 |
| **폴더 넣으면 기본 게임이 사라짐** | 짝맞추기를 파일 이름으로 함. `2048.gb` 는 흔한 이름 |
| **게임 중 MENU 가 "KEEP" 이 되고 안 먹힘** | 롬 읽는 동안 뜬 확인창이 게임 화면까지 따라옴 |
| 200개 넣으면 앱이 죽음 | `getAll()` 이 롬 내용까지 통째로 메모리에 올림 |
| 빈 곳을 톡 쳤는데 게임이 켜짐 | 길게누르기에 `pointerId` 를 안 묶음 |

## ★★ 이 프로젝트 최대의 교훈

> **"전부 통과" 를 믿지 마세요. 무엇을 안 보고 있는지를 보세요.**

실제로 있었던 일들입니다.

- `RomStore` 가 **한 줄도 실행되지 않고** 있었습니다 — 가짜가 `indexedDB=undefined` 였고,
  화면 검사는 자기만의 가짜 보관소를 썼습니다. 심각한 버그 셋이 거기 숨어 있었습니다.
- **지우기 확인 화면이 한 번도 안 그려졌습니다** — 저장소가 막혀 있어 기본 게임만 있었고,
  기본 게임은 못 지우니까요. 파일 이름을 화면에 내보내는 유일한 자리인데 말입니다.
- **`setTimeout` 이 가짜에서 아무것도 안 했습니다** — 길게누르기가 한 번도 안 돌았습니다.
- "시계를 걸어뒀다" 검사가 **`fit` 의 700ms 타이머 덕분에 공허하게 참**이었습니다.
- "누르고 있어도 한 칸만" 을 **5프레임**으로 돌렸는데 목록이 마침 **5줄**이라,
  고장나도 한 바퀴 돌아 제자리로 왔습니다.
- 가짜 IndexedDB 가 **쓰기 트랜잭션을 줄 세우지 않아서**, 멀쩡한 코드를 버그로 오해할 뻔했습니다.

## ★ 방해검사(sabotage) 를 하세요

고친 뒤에는 **일부러 망가뜨려서 검사가 실제로 잡는지** 확인하세요.
안 하면 "통과하지만 아무것도 안 보는 검사"가 쌓입니다.

```bash
cp ui.js /tmp/u.bak
python3 -c "p='ui.js'; s=open(p,encoding='utf8').read();
            s=s.replace('원래 줄','망가뜨린 줄',1); open(p,'w',encoding='utf8').write(s)"
node test/all.js | grep -c 실패      # 0 이 나오면 그 검사는 가짜입니다
cp /tmp/u.bak ui.js
```

반드시 긍정형 단언(무엇이 실제로 일어났는가)을 하나는 끼워 넣으세요.

## 가짜 환경에서 조심할 것

| | |
|---|---|
| `let` 로 선언한 값 | 샌드박스의 속성이 **안 됩니다.** `read("이름")` 으로 안에서 평가해야 읽힙니다 |
| 그래서 | 검사에서 봐야 하는 값은 **함수 밖(맨 위)에** 두세요 (`gpPrev`, `gpRaf` 처럼) |
| `addEventListener` | `this` 가 샌드박스가 아니라 대리자입니다. `this._l` 로 모으면 못 찾습니다 |
| 버튼 누르기 | **뗄 때까지 눌린 채로 남습니다.** `tap()` 을 쓰세요 (누르고 떼기) |
| `setTimeout` / `rAF` | 적어뒀다가 `flush()` / `frame()` 으로 직접 터뜨립니다 |
| 프레임 수 | **목록 길이와 같게 잡지 마세요.** 한 바퀴 돌아 제자리가 되어 가짜 통과가 납니다 |
