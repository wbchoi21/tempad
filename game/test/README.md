# 게임 모드 검사

```
node test/all.js
```

브라우저 없이 검사합니다. 고칠 때마다 돌리세요.

| 파일 | 무엇을 |
|---|---|
| `run.js` | 에뮬레이터 다루기·저장·비정상 종료 방어 (가짜 환경) |
| `ui.js` | 화면 흐름 — 목록, 메뉴, 저장 칸, 버튼이 새지 않는가 |
| `pad.js` | 터치 십자키 — 떨림, 전화 왔을 때, 두 손 동시 |
| `live.js` | **★ 진짜 binjgb + 진짜 롬** |

## live.js 가 특별합니다

`binjgb.wasm` 을 노드에서 그대로 실행합니다. 가짜가 아닙니다.
진짜 2048 과 토부토부걸을 돌려서 화면이 나오는지, 주황으로 칠해지는지,
저장했다 되돌리면 그 시점으로 돌아오는지까지 확인합니다.

**여기서 진짜 버그를 잡았습니다.** → `game.js` 의 `destroy()` 주석 참고.
가짜 환경으로는 절대 안 잡혔을 것입니다.

## 여기서 알 수 없는 것

- 실제로 폰 화면에 보이는지
- 속도가 60프레임 나오는지
- 손으로 만졌을 때 느낌

이 셋은 폰에서 직접 봐야 합니다.
