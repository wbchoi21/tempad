
브라우저 없이 검사합니다. 고칠 때마다 돌리세요. **310개**입니다.

| 파일 | 무엇을 |
|---|---|
| `run.js` | 에뮬레이터 다루기·저장·비정상 종료 방어 (가짜 환경) |

| `pad.js` | 터치 십자키 — 떨림, 전화, 두 손 동시 |
| `page.js` | `index.html` 안의 코드를 진짜로 실행 |
| `live.js` | **진짜 binjgb + 진짜 롬** |

## 여기서 실제로 잡은 버그들

교차검사 3라운드에서 **16개**가 나왔습니다. 특히 이런 것들:

| 증상 | 원인 |
|---|---|
| **세이브 71번이면 에뮬레이터가 죽음** | `_file_data_delete` 뒤에 `_free(ptr)` 를 안 함. 한 번에 195KB 씩 영구 소실 |
| 같은 롬을 다시 넣으면 저장이 통째로 사라짐 | `tx()` 가 결과를 벗기는 방식이 제각각이라 "이미 있나" 검사가 항상 거짓 |
| 불러오기 실패를 성공이라고 말함 | `_emulator_read_state` 반환값을 버림 |
| 롬 읽는 사이에 나가면 뒤에서 계속 돎 | 시작할 때 세대 대조를 안 함 |
| 다른 앱 갔다 오면 멈춘 채로 갇힘 | `visible` 로 돌아왔을 때 처리가 없음 |
| 낡은 기록 하나가 목록 전체를 날림 | `r.states.map` 이 터지면 목록이 통째로 실패 |
