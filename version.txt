★ "올렸는데 안 바뀐다" 의 원인을 고쳤습니다 (sw.js)
  게임 기능은 전부 .js 파일에 들어 있는데, 그 파일들만 "폰에 저장해둔 것
  먼저" 로 되어 있었습니다. 그래서 제대로 올려도 게임 쪽은 옛날 그대로였습니다.
  이제 글자로 된 파일은 전부 인터넷에서 먼저 확인합니다.
  이번 한 번만 캐시를 지워주셔야 합니다 (아래 참고).

★★ 블루투스 게임패드를 꽂으면 그냥 됩니다
    설정할 것 없습니다. 폰에 연결하고 아무 버튼이나 한 번 누르면
    화면 아래 GAMEPAD 라고 뜹니다. 터치 조작도 그대로 살아 있어서
    둘 다 동시에 씁니다.

      오른쪽 버튼        A        (게임보이는 A 가 오른쪽입니다)
      아래·왼쪽·위 버튼   B        헷갈리지 말라고 셋 다 B 로
      SELECT / START     그대로
      십자키 / 왼쪽 스틱  이동 (대각선 됩니다)
      L 또는 R           MENU — 저장·나가기까지 패드만으로

    ※ 유리판 십자키는 손끝에 걸리는 턱이 없어서, 아무리 다듬어도
      진짜 십자키를 못 이깁니다. 8BitDo 같은 것 3만원대면 삽니다.
      그거 물리면 조작 이야기는 그날로 끝납니다.

★ 조작이 훨씬 부드러워졌습니다
    · 대각선이 됩니다 (전에는 4방향뿐이라 젤다·마리오가 극악이었습니다)
      위+오른쪽처럼 두 방향이 동시에 눌립니다. 진짜 십자키와 같습니다
    · 대각선으로 꺾을 때 가던 방향이 안 끊깁니다
    · 십자키를 조금만 밀어도 먹습니다 (밀어야 하는 거리 55% → 38%)
    · A·B 버튼이 커졌습니다 (46 → 58). 보이는 동그라미보다
      실제 누르는 면이 사방 10px 더 넓습니다
    · SELECT·START 도 커졌습니다

  ※ 십자키 + A + B 를 동시에 누르는 건 원래도 됩니다.
    안 됐다면 버튼이 작아서 빗나간 것입니다.

★ 실수로 밖으로 튕기던 문제를 없앴습니다
    화면 왼쪽 아래 "< TVA // FIELD UNIT" 이 나가는 버튼이었는데,
    십자키 바로 옆이라 게임 중에 엄지가 스치면 그대로 나가버렸습니다.
    이제 그냥 이름표입니다. 눌러도 아무 일 없습니다.

[ 게임에서 메인화면으로 나가는 길 — 두 개 ]

  게임 중이면
    MENU 버튼 → PAUSED → 맨 아래 EXIT → A

  기기 고르는 화면(SELECT SYSTEM)이면
    MENU 버튼 → EXIT → A
    (전에는 이 화면에서 MENU 가 "—" 로 죽어 있었습니다)

  ※ 둘 다 커서가 EXIT 가 아닌 곳에서 시작합니다.
    잘못 눌러도 한 번에 안 나가게요.

이번에 바뀐 것

  LIBRARY  (게임 목록에서 SELECT)
    ADD FILE     파일 하나 또는 여러 개
    ADD FOLDER   폴더 안의 게임을 한 번에 전부
    REMOVE       고른 게임 지우기
    BACK         목록으로

  · ADD FOLDER 는 어느 폰에나 있습니다.
    아이폰은 진짜 폴더 고르기가 안 되어서 파일창이 열립니다.
    폴더를 열고 파일을 전부 선택하면 됩니다. 화면에도 그렇게 적혀 있습니다.

  · 지울 때는 반드시 한 번 물어봅니다. 되돌릴 수 없기 때문입니다.
      지움  = START
      안 지움 = A / B / MENU  (그리고 창이 뜬 뒤 0.4초는 아무것도 안 받음)
    지우는 걸 A 에 안 건 이유: 목록에서 A 는 늘 "시작" 이었습니다.
    그 손버릇 그대로 누르면 게임이 사라집니다.

  · 목록에서 게임을 0.9초 길게 눌러도 같은 물음이 뜹니다 (지름길)
  · 손가락으로 줄을 눌러 고를 수 있습니다. 고른 줄을 또 누르면 시작
  · 기본으로 들어있는 5개는 못 지웁니다
