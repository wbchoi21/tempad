★★ 2. 메뉴를 손가락으로 누르게 바꿨습니다

    전에는 버튼이 넷뿐이라 메뉴까지 거기에 겹쳐 걸었습니다.
      SELECT 를 누르면 라이브러리, START 를 누르면 파일 넣기,
      지울 때는 START 가 "지운다"…
    외울 게 너무 많았습니다.

    이제 이렇게 갈라놨습니다.

      십자키 · A · B · L · R · SELECT · START →  게임에만 들어갑니다
      메뉴 · 목록 · 확인창 · 토글            →  손가락으로 직접 누릅니다

    · 목록에서 한 번 두드리면 고르기, 그 줄을 또 두드리면 시작
    · 손가락으로 목록을 훑어 내릴 수 있습니다
    · 게임을 0.9초 길게 누르면 지울까 물어봅니다
    · 지우기는 화면의 [DELETE] 를 눌러야 합니다 ([KEEP] 은 안 지움)
    · 일시정지 메뉴의 저장 칸마다 [LOAD] [SAVE] 버튼이 따로 있습니다


★★ 3. 오른쪽 위에 버튼 세 개가 생겼습니다

    게임 조작판에서 멀리 떨어뜨려 뒀습니다. 게임에 아무 영향이 없습니다.

      MENU   메뉴 열기 (화면에 따라 BACK / EXIT / RESUME 으로 바뀝니다)
      AMBER  화면 색 바꾸기 — 템패드 주황 ↔ 게임 본래 색
      PAD    터치 조작판 숨기기 (게임패드 쓸 때. 화면이 커집니다)

    ★ 조작판을 숨겨도 이 세 개는 그대로 남습니다. 갇힐 일이 없습니다.


★★ 4. 화면이 폰 크기에 맞춰 최대로 커집니다

    비율은 절대 안 건드립니다. 늘리지도, 자르지도 않습니다.
    남는 좌우 여백에 조작판이 앉습니다.
    "전체화면 모드" 같은 건 따로 없습니다 — 늘 최대입니다.


★★ 5. 게임패드에서 메뉴 여는 법이 바뀌었습니다

      전 : L 또는 R 을 혼자 누르면 메뉴
      후 : SELECT + L + R 을 한꺼번에

    GBA 는 L·R 이 진짜 게임 버튼이라서 그렇습니다.
    그대로 두면 드리프트하려고 R 을 누른 순간 게임이 멈춥니다.


★ 6. 눈에 안 보이지만 중요한 것

    · 화면 버튼을 누르는 방식을 바꿨습니다. 전에는 아이폰에서
      **MENU 가 안 눌릴 수 있는** 구조였습니다 (게임에서 못 나옴).
      이제 그럴 수 없게 바꿨습니다.
    · 저장할 때마다 메모리가 조금씩 새던 버그를 검사로 잡아냈습니다.
      (저장 300번을 반복해도 안 늘어나는지 자동으로 봅니다.)
