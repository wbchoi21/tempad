    GAME BOY  /  GAME BOY COLOR  /  GAME BOY ADVANCE

    게임&워치 칸은 없앴습니다 (만들어 넣은 게 하나도 없었습니다).

    ★ 파일을 넣으면 **롬 속을 보고 제 기기로 알아서 보냅니다.**
      게임보이 목록에서 .gbc 를 넣어도 컬러 목록으로 갑니다.
      어디로 갔는지 화면 아래에 적어줍니다.

      "GBA EMULATOR NOT AVAILABLE" 이라고 뜹니다. 검은 화면이 아니라
      이유가 뜨게 해뒀습니다. 알맹이만 넣으면 그대로 굴러갑니다.


★★ 2. 메뉴를 손가락으로 누르게 바꿨습니다

    전에는 버튼이 넷뿐이라 메뉴까지 거기에 겹쳐 걸었습니다.
      SELECT 를 누르면 라이브러리, START 를 누르면 파일 넣기,
      지울 때는 START 가 "지운다"…
    외울 게 너무 많았습니다.

    이제 이렇게 갈라놨습니다.

      십자키 · A · B · L · R · SELECT · START →  게임에만 들어갑니다
      메뉴 · 목록 · 확인창 · 토글            →  손가락으로 직접 누릅니다

    · 목록에서 한 번 두드리면 고르기, 그 줄을 또 두드리면 시작
    · 손가락으로 목록을 훑어 내릴 수 있습니다
    · 게임을 0.9초 길게 누르면 지울까 물어봅니다
    · 지우기는 화면의 [DELETE] 를 눌러야 합니다 ([KEEP] 은 안 지움)
    · 일시정지 메뉴의 저장 칸마다 [LOAD] [SAVE] 버튼이 따로 있습니다


★★ 3. 오른쪽 위에 버튼 세 개가 생겼습니다

    게임 조작판에서 멀리 떨어뜨려 뒀습니다. 게임에 아무 영향이 없습니다.

      MENU   메뉴 열기 (화면에 따라 BACK / EXIT / RESUME 으로 바뀝니다)
      AMBER  화면 색 바꾸기 — 템패드 주황 ↔ 게임 본래 색
      PAD    터치 조작판 숨기기 (게임패드 쓸 때. 화면이 커집니다)

    ★ 조작판을 숨겨도 이 세 개는 그대로 남습니다. 갇힐 일이 없습니다.


★★ 4. 화면이 폰 크기에 맞춰 최대로 커집니다

    비율은 절대 안 건드립니다. 늘리지도, 자르지도 않습니다.
    남는 좌우 여백에 조작판이 앉습니다.
    "전체화면 모드" 같은 건 따로 없습니다 — 늘 최대입니다.


★★ 5. 게임패드에서 메뉴 여는 법이 바뀌었습니다

      전 : L 또는 R 을 혼자 누르면 메뉴
      후 : SELECT + L + R 을 한꺼번에

    GBA 는 L·R 이 진짜 게임 버튼이라서 그렇습니다.
    그대로 두면 드리프트하려고 R 을 누른 순간 게임이 멈춥니다.


★ 6. 눈에 안 보이지만 중요한 것

    · 화면 버튼을 누르는 방식을 바꿨습니다. 전에는 아이폰에서
      **MENU 가 안 눌릴 수 있는** 구조였습니다 (게임에서 못 나옴).
      이제 그럴 수 없게 바꿨습니다.
    · 저장할 때마다 메모리가 조금씩 새던 버그를 검사로 잡아냈습니다.
      (저장 300번을 반복해도 안 늘어나는지 자동으로 봅니다.)

 새로 생긴 것 — zip 하나로 게임 여러 개 넣기
═══════════════════════════════════════════════════════════════════

★★ 게임 목록에 [+ ADD ZIP] 이 생겼습니다

   카톡으로 zip 을 받아서 그것 하나만 고르면 됩니다.
   앱이 알아서 —
     · 압축을 풀고
     · 진짜 게임만 골라내고 (사진·설명서·맥 껍데기는 버립니다)
     · GB / GBC / GBA 목록으로 나눠 넣습니다

   20개를 하나씩 고르던 것이 **한 번**으로 줄었습니다.

   ※ 이미 있는 게임이 zip 에 또 있어도 괜찮습니다.
     세이브와 저장 칸이 그대로 남습니다. 두 번 안 들어갑니다.

★★ 안드로이드는 한 단계 더 짧습니다

   카톡에서 zip 을 길게 눌러 **공유 → TEMPAD** 하면 바로 들어갑니다.
   저장했다가 다시 찾아 고를 필요가 없습니다.
   (홈 화면에 추가해 두어야 공유 목록에 뜹니다. 아이폰은 이 기능이 없어서
    지금처럼 [+ ADD ZIP] 으로 고르면 됩니다.)

★ 잘못된 zip 은 이유를 말해줍니다

   암호 걸림 / 파일 깨짐 / 폰이 낡아서 못 푸는 경우를 각각 다르게 알려줍니다.
   "안 됨" 만 뜨면 무엇을 해야 할지 알 수 없으니까요.

   · 카톡 전송이 끊겨 덜 받은 zip → "다시 받아라" 고 말합니다
   · zip 안에 또 zip 이 있으면    → "먼저 풀어라" 고 말합니다
   · 저장공간이 꽉 찼으면         → 게임이 하나뿐이어도 용량 이야기를 합니다

 2026-08-11j — 교차검사에서 나온 것들을 고쳤습니다
═══════════════════════════════════════════════════════════════════

★★ 안드로이드 "공유 → TEMPAD" 가 **한 번도 동작하지 않고 있었습니다**

   세 군데가 동시에 어긋나 있었고, 전부 **조용히** 실패해서
   화면에는 아무 글자도 안 떴습니다. 셋 다 고쳤습니다.

     · 넣어두는 자리와 찾는 자리가 서로 달랐습니다
     · 공유 뒤에 게임 화면이 아니라 **본체 화면**으로 갔습니다
     · 판올림이 내려오면 넣어둔 zip 을 지워버렸습니다

   ★ 여러 개를 한꺼번에 공유해도 이제 전부 들어갑니다 (전엔 첫 개만).
   ★ 공유가 잘못되면 잘못됐다고 말해줍니다 (전엔 화면만 열렸습니다).

★★ 넣기가 **말없이 사라지는** 경우를 없앴습니다

   마지막에 화면에 남는 글자가 거짓말이 되는 게 제일 나쁩니다.

     · 넣는 중에 또 누르면 → "N MORE NOT ADDED — TRY AGAIN"
       (전에는 "ADDED 8" 로 덮여서 다 들어간 줄 알았습니다)
     · 삭제 물음표가 떠 있는 중에 넣으면 → "FINISH THE QUESTION FIRST"
       (전에는 12개짜리 zip 이 통째로 사라진 채 안내칸이 비어 있었습니다)

★★ zip 을 잘못 읽던 것 다섯 가지

   전부 "멀쩡한 zip 인데 게임이 없다고 하거나 깨졌다고 하던" 것들입니다.

     · 압축이 잘 된 롬일수록 거절당했습니다 (패딩 큰 덤프)
     · 주석이 붙은 zip 이 "빈 zip" 으로 보였습니다
     · 어떤 압축 도구가 만든 zip 이 통째로 깨진 것으로 보였습니다
     · 앞에 뭔가 붙은 zip 은 zip 으로 알아보지도 못했습니다
     · 무압축 항목이 크기를 속이면 폰 메모리를 밀 수 있었습니다

★ 안드로이드에서 zip 이 회색으로 안 눌리던 것도 고쳤습니다.
